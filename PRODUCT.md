# Product Documentation

## Freelancer Booking Platform

---

## 🎯 Product Vision

A trusted, invite-only marketplace that connects photography and videography companies with verified freelance professionals, streamlining the booking process from job posting to payment completion.

---

## 👥 User Personas

### 1. **Admin**

**Role**: Platform Manager  
**Goal**: Maintain platform quality and oversee operations  
**Pain Points**: Need to control user access, monitor platform health, ensure quality control

### 2. **Company**

**Role**: Hiring Manager / Production Company  
**Goal**: Find reliable, skilled freelancers for photography/videography gigs  
**Pain Points**: Vetting freelancers, managing contracts, tracking bookings, payment records

### 3. **Freelancer**

**Role**: Photography/Videography Professional  
**Goal**: Find consistent work opportunities with clear terms  
**Pain Points**: Finding gigs, unclear contracts, payment uncertainty, showcasing portfolio

---

## 📖 User Stories

### Admin Portal

#### Invite Management

**US-A01**: As an **admin**, I want to **create invitation links with specific roles**, so that **I can control who joins the platform and in what capacity**.

**US-A02**: As an **admin**, I want to **set expiration dates on invites**, so that **old or unused links don't compromise platform security**.

**US-A03**: As an **admin**, I want to **view all invites and their status** (pending/accepted/expired), so that **I can track my invitation campaign effectiveness**.

**US-A04**: As an **admin**, I want to **delete unused invites**, so that **I can manage and clean up my invitation list**.

#### User Management

**US-A05**: As an **admin**, I want to **view all registered users across all roles**, so that **I have complete visibility of the platform community**.

**US-A06**: As an **admin**, I want to **see each user's onboarding status**, so that **I can identify users who need assistance completing their profiles**.

**US-A07**: As an **admin**, I want to **filter users by role** (admin/company/freelancer), so that **I can quickly find specific user types**.

**US-A08**: As an **admin**, I want to **see when users joined**, so that **I can track platform growth over time**.

#### Platform Analytics

**US-A09**: As an **admin**, I want to **view total user counts by role**, so that **I understand the platform's user distribution**.

**US-A10**: As an **admin**, I want to **see total job postings and active jobs**, so that **I can gauge platform activity levels**.

**US-A11**: As an **admin**, I want to **view booking statistics by status**, so that **I understand conversion rates and booking success**.

**US-A12**: As an **admin**, I want to **see recent activity metrics** (last 7 days), so that **I can monitor platform momentum**.

**US-A13**: As an **admin**, I want to **view acceptance rates and completion percentages**, so that **I can measure platform health and user satisfaction**.

### Company Portal

#### Onboarding

**US-C01**: As a **company**, I want to **complete my profile with company details** (name, contact person, WhatsApp, location, year started), so that **freelancers can learn about my business**.

**US-C02**: As a **company**, I want to **upload my company logo**, so that **my listings look professional and recognizable**.

**US-C03**: As a **company**, I want to **see my onboarding progress**, so that **I know what information is still required**.

**US-C04**: As a **company**, I want to **create job postings with detailed requirements** (title, description, dates, location, budget, job type, time), so that **I attract the right freelancers**.

**US-C05**: As a **company**, I want to **specify multiple dates for a job**, so that **I can communicate multi-day shoots or flexible scheduling**.

**US-C06**: As a **company**, I want to **set contract terms with checkboxes** (content posting, advance payment, payment after shot, content ownership, SD card), so that **expectations are clear upfront**.

**US-C07**: As a **company**, I want to **add additional contract details**, so that **I can include custom requirements not covered by standard terms**.

**US-C08**: As a **company**, I want to **toggle job status between active/inactive**, so that **I can control visibility of my postings without deleting them**.

**US-C09**: As a **company**, I want to **view all my posted jobs**, so that **I can track my hiring pipeline**.

#### Application Review

**US-C10**: As a **company**, I want to **view all responses to my job postings**, so that **I can evaluate interested freelancers**.

**US-C11**: As a **company**, I want to **see complete freelancer profiles** (portfolio, equipment, verification status), so that **I can make informed hiring decisions**.

**US-C12**: As a **company**, I want to **view freelancer portfolio links**, so that **I can assess their work quality and style**.

**US-C13**: As a **company**, I want to **see freelancer equipment lists**, so that **I know what gear they bring to the job**.

**US-C14**: As a **company**, I want to **see freelancer verification status**, so that **I can trust their credentials**.

#### Booking Management

**US-C15**: As a **company**, I want to **send booking requests to freelancers**, so that **I can formally offer them the job**.

**US-C16**: As a **company**, I want to **view bookings by status** (pending, accepted, rejected, completed), so that **I can organize my upcoming and past projects**.

**US-C17**: As a **company**, I want to **mark accepted bookings as paid** with amount and date, so that **I maintain accurate payment records**.

**US-C18**: As a **company**, I want to **view payment history for completed bookings**, so that **I have financial records for accounting**.

**US-C19**: As a **company**, I want to **contact freelancers via WhatsApp directly from their profile**, so that **I can quickly communicate**.

### Freelancer Portal

#### Onboarding

**US-F01**: As a **freelancer**, I want to **create my profile with personal details** (name, location, WhatsApp), so that **companies can contact me**.

**US-F02**: As a **freelancer**, I want to **upload my profile photo**, so that **my profile looks professional**.

**US-F03**: As a **freelancer**, I want to **list my equipment**, so that **companies know what gear I own**.

**US-F04**: As a **freelancer**, I want to **add up to 3 portfolio links**, so that **I can showcase my best work**.

**US-F05**: As a **freelancer**, I want to **upload my ID proof** (Aadhaar or other), so that **I can get verified on the platform**.

**US-F06**: As a **freelancer**, I want to **see my verification status**, so that **I know if my credentials are approved**.

#### Job Discovery

**US-F07**: As a **freelancer**, I want to **browse all active job postings**, so that **I can find work opportunities**.

**US-F08**: As a **freelancer**, I want to **see job details** (dates, budget, location, time, description), so that **I can evaluate if it's a good fit**.

**US-F09**: As a **freelancer**, I want to **view company information for each job**, so that **I know who I'd be working with**.

**US-F10**: As a **freelancer**, I want to **see when jobs were posted**, so that **I can prioritize recent opportunities**.

**US-F11**: As a **freelancer**, I want to **view contract terms before applying**, so that **I understand all requirements upfront**.

#### Application Process

**US-F12**: As a **freelancer**, I want to **express interest in a job with an optional message**, so that **I can introduce myself to the company**.

**US-F13**: As a **freelancer**, I want to **mark jobs as "not interested"**, so that **I can declutter my job feed**.

**US-F14**: As a **freelancer**, I want to **be prevented from applying twice to the same job**, so that **I don't accidentally submit duplicate applications**.

**US-F15**: As a **freelancer**, I want to **see which jobs I've already applied to**, so that **I don't waste time reviewing them again**.

#### Booking Management

**US-F16**: As a **freelancer**, I want to **view all booking requests sent to me**, so that **I can respond to job offers**.

**US-F17**: As a **freelancer**, I want to **filter bookings by status** (pending, accepted, rejected, completed), so that **I can organize my work schedule**.

**US-F18**: As a **freelancer**, I want to **see job overview before accepting** (dates, time, payment, company contact), so that **I can make an informed decision**.

**US-F19**: As a **freelancer**, I want to **review the complete contract before accepting**, so that **I fully understand what I'm agreeing to**.

**US-F20**: As a **freelancer**, I want to **accept bookings through a three-step flow** (overview → contract → confirmation), so that **I don't miss any important details**.

**US-F21**: As a **freelancer**, I want to **see a confirmation warning if I try to decline**, so that **I don't accidentally reject opportunities**.

**US-F22**: As a **freelancer**, I want to **download accepted bookings to my calendar (.ics file)**, so that **I can add them to my personal scheduling system**.

**US-F23**: As a **freelancer**, I want to **see when a booking is marked as paid**, so that **I have confirmation of payment receipt**.

## 🚀 User Journeys

### Journey 1: Company Hiring a Freelancer

```
1. Company receives invite link from admin
2. Company signs up with invite code
3. Company completes onboarding profile
4. Company posts a job with requirements and contract terms
5. Freelancers apply to the job
6. Company reviews freelancer profiles and portfolios
7. Company sends booking request to chosen freelancer
8. Freelancer accepts the booking
9. Shoot happens
10. Company marks booking as paid
11. Booking marked as completed
```

**Key Touchpoints**: Invite → Onboarding → Job Post → Application Review → Booking Request → Payment Tracking

---

### Journey 2: Freelancer Finding Work

```
1. Freelancer receives invite link from admin
2. Freelancer signs up with invite code
3. Freelancer completes onboarding profile (photos, equipment, portfolio, ID proof)
4. Freelancer browses active job postings
5. Freelancer views job details and contract terms
6. Freelancer applies to interesting jobs with optional message
7. Company sends booking request
8. Freelancer reviews job overview
9. Freelancer reviews full contract
10. Freelancer accepts booking
11. Freelancer downloads calendar event
12. Freelancer completes the shoot
13. Freelancer receives payment confirmation
```

**Key Touchpoints**: Invite → Onboarding → Job Browse → Application → Booking Review → Contract Acceptance → Calendar Integration → Payment Confirmation

---

### Journey 3: Admin Managing Platform

```
1. Admin logs into platform
2. Admin views platform metrics dashboard
3. Admin creates invitation links for new users
4. Admin shares invite links with vetted individuals
5. Admin monitors user onboarding progress
6. Admin reviews platform activity (jobs, bookings, responses)
7. Admin identifies and addresses any issues
```

**Key Touchpoints**: Dashboard → Invite Creation → User Monitoring → Platform Analytics

## 🤔 Design Decisions & Rationale

### Why Invite-Only?

**Decision**: Platform requires invitation links for signup  
**Rationale**:

- Ensures quality control in early stages
- Builds trust through vetted community
- Prevents spam and fake accounts
- Creates exclusivity and value perception
- Allows gradual scaling

### Why Three-Step Booking Acceptance?

**Decision**: Freelancers must go through overview → contract → confirmation  
**Rationale**:

- Reduces misunderstandings and disputes
- Ensures contract is actually read
- Provides clear opportunity to decline
- Creates paper trail of acceptance
- Builds professional booking culture

### Why Multiple Portfolio Links?

**Decision**: Up to 3 portfolio links instead of unlimited  
**Rationale**:

- Encourages freelancers to showcase their best work
- Easier for companies to review quickly
- Maintains profile cleanliness
- Balances showcase needs with simplicity

### Why Contract Checkboxes?

**Decision**: Standard contract terms with checkboxes plus custom field  
**Rationale**:

- Common terms are standardized for clarity
- Checkboxes are scannable and clear
- Custom field allows flexibility
- Reduces contract negotiation time
- Sets professional standards

### Why Payment Tracking (Not Processing)?

**Decision**: Track payments, don't process them  
**Rationale**:

- Simpler MVP, fewer regulations
- Allows flexibility in payment methods
- Reduces platform liability
- Lower transaction fees for users
- Can add processing later if needed

## 💡 Product FAQ

**Q: Can users sign up without an invite?**  
A: No. The platform is invite-only to maintain quality and trust.

**Q: How do freelancers get verified?**  
A: Admins review uploaded ID proofs and manually update verification status.

**Q: Can companies edit jobs after posting?**  
A: Not currently in MVP. They can toggle active/inactive status. Editing feature may be added in future phases.

**Q: What happens if a freelancer doesn't accept a booking request?**  
A: It remains in "pending" status. Companies can see if it's been viewed (future feature) or follow up via WhatsApp.

**Q: Can freelancers apply to the same job twice?**  
A: No. The system prevents duplicate applications to the same job.

**Q: How are payments processed?**  
A: Currently, payments happen outside the platform (bank transfer, UPI, etc.). Companies mark them as paid for record-keeping.

**Q: Can admins see all platform data?**  
A: Yes. Admins have full visibility for platform management and user support.

**Q: What calendar apps are supported?**  
A: Any app that accepts .ics files (Google Calendar, Apple Calendar, Outlook, etc.)

**Q: Can users have multiple roles?**  
A: No. Each user has one role (admin, company, or freelancer).

**Q: Is there a mobile app?**  
A: Not yet. The web platform is fully mobile-responsive. Native apps are in the roadmap.
